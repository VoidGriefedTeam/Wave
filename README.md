## What is Wave?

**Wave** is a programming language designed to make development fast, simple, and enjoyable while targeting **C++** as its output language.

Wave takes inspiration from the simplicity of Python and combines it with the power of C++.

The idea is simple:

> **Write code quickly like Python, generate C++, and compile it into a native executable.**

Instead of manually writing C++ boilerplate for simple programs, Wave lets you express the same idea with a much smaller amount of code — then hands you the generated `.cpp` file (and optionally a compiled binary).

## Why Wave?

Programming should be about solving problems, not repeatedly writing boilerplate.

C++ is extremely powerful, but even a tiny program requires additional structure:

```cpp
#include <print>

int main() {
    std::print("Hello, World!");
}
```

Wave aims to make that development process faster:

```wave
print("Hello, World!")
```

Wave handles the includes, the `main` function, and the standard-library call so you can focus on the logic.

## Example

#### Wave (`examples/code.wave`)

```wave
print("hi")
println("prints new line")
cos(90)
```

#### Generated C++

```cpp
#include <print>
#include <cmath>

int main() {
    std::print("hi");
    std::println("prints new line");
    std::cos(90);
}
```

## How It Works

Wave compiles source in four stages, mirroring the pipeline in `src/`:

1. **Lex** (`lexer.cpp`) — reads the `.wave` file and parses it into words, then extracts function calls and their arguments from the parentheses.
2. **Translate** (`translator.cpp`) — looks up each recognized keyword in a JSON dictionary (`cpp_dic/dic.json`) and substitutes the argument into the matching C++ template, collecting the required `#include`s along the way.
3. **Generate** (`generator.cpp`) — deduplicates includes and assembles the final `.cpp` file, wrapping the translated statements in a `main` function.
4. **Build** (optional, `main.cpp`) — if requested, Wave shells out to a native compiler to produce an executable directly.

Because the keyword-to-C++ mapping lives in a plain JSON file rather than hardcoded logic, adding new built-ins to Wave is mostly a matter of editing `cpp_dic/dic.json` — see [Extending Wave](#-extending-wave).

## Building From Source

### Requirements

- CMake **4.2+**
- A C++23 compiler:
  - **Windows:** MSVC (Visual Studio Build Tools 2026)
  - **Linux:** GCC (`g++`) with C++23 support
- [Ninja](https://ninja-build.org/) (used by the provided CMake preset)

### Build

```bash
git clone https://github.com/VoidGriefedTeam/Wave.git
cd Wave
cmake --preset default
cmake --build --preset default
```

The `wave` executable will be placed in the `build/` directory, with `cpp_dic/` copied alongside it so it can find its keyword dictionary regardless of your working directory.

## Usage

```bash
wave <input.wave> [options]
```

| Option | Description |
|---|---|
| `input` | Path to the `.wave` source file (required) |
| `-o, --output` | Path for the generated `.cpp` file (defaults to `<input>.cpp`) |
| `--build` | Compile the generated C++ into a native executable after generation |

### Examples

Generate C++ from a Wave file:

```bash
wave examples/code.wave
```

Generate and immediately compile it into a binary:

```bash
wave examples/code.wave --build
```

With `--build`, Wave detects your OS and compiler automatically. On Windows it locates MSVC via `vswhere` (offering to install the Build Tools if missing); on Linux it looks for `g++` (offering an install command for `apt`, `dnf`, `pacman`, or `zypper` if missing).

## Extending Wave

Every built-in in Wave is defined declaratively in [`cpp_dic/dic.json`](cpp_dic/dic.json). Each entry maps a Wave keyword to the C++ it should generate:

```json
"sqrt()": {
    "import": "<cmath>",
    "code": "std::sqrt(DATA);",
    "data": ["DATA"]
}
```

- **`import`** — the header Wave will include if this keyword is used.
- **`code`** — the C++ template emitted for this call, with a placeholder token.
- **`data`** — the placeholder token(s) in `code` that get replaced with the arguments passed in Wave.

Adding a new function to the language is as simple as adding a new entry — no changes to the lexer or generator required.

## Project Structure

```
Wave/
├── src/               # Compiler source (lexer, translator, generator, CLI entry point)
├── cpp_dic/dic.json   # Keyword → C++ translation dictionary
├── examples/          # Sample .wave programs
├── THIRD_PARTY/        # Bundled dependencies (CLI11, fmt, glaze)
└── CMakeLists.txt     # Build configuration
```

## Dependencies

Wave bundles the following third-party libraries under `THIRD_PARTY/` (see [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) for full license text):

- [CLI11](https://github.com/CLIUtils/CLI11) — command-line argument parsing
- [fmt](https://github.com/fmtlib/fmt) — formatting and colored terminal output
- [glaze](https://github.com/stephenberry/glaze) — JSON parsing for the keyword dictionary

## Roadmap

Wave is early-stage. Planned directions include expanding the keyword dictionary, adding control flow and variables beyond simple function calls, and improving error diagnostics.
